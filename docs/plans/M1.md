## Tables (Identity owns all of them; added to `IdentityServiceProvider::TABLES`)

| Table | Key columns |
|---|---|
| `users` (extended) | `email` citext unique, `username` citext unique, `phone_e164` encrypted + `phone_hash` unique, `role` (fan, creator, moderator, admin), `status` (active, paused, suspended, banned), `mfa_enabled`, `age_verified_at`, `last_login_at` |
| `user_devices` | ULID, `user_id`, `device_fingerprint_hash`, `label` ("Chrome on Samsung A54"), `last_ip`, `last_city`, `last_seen_at`, `revoked_at`; index(`user_id`, `revoked_at`) |
| `webauthn_credentials` | passkeys per user (package schema, ULID keys) |
| `mfa_totp` | `user_id`, secret (encrypted), `confirmed_at` |
| `mfa_recovery_codes` | hashed codes, `used_at` |
| `phone_verifications` | `user_id`, code hash, `attempts`, `expires_at` |
| `age_verifications` | `user_id`, `provider_ref`, `purpose`, `status`, `checked_at` (no images; date of birth only encrypted, rule 10) |

## Actions

- `RegisterFan`
- `VerifyPhone` (6-digit code through `SmsSender`, hashed, 5 attempts, 10 min)
- `StartAgeVerification` / `CompleteAgeVerification` (through `IdentityVerifier`)
- `LoginWithPassword`
- `LoginWithPasskey`
- `RegisterPasskey`
- `EnableTotp` / `ConfirmTotp` / `UseRecoveryCode`
- `RegisterDevice`: refuses a 4th active device and returns the active list
- `RevokeDevice` / `SignOutOtherDevices`
- `RequireStepUp`: reusable for payouts in M3 and consent in M7

Events: `UserRegistered`, `AgeVerified`, `DeviceRevoked`, all after commit. Every login, MFA change and device revocation writes to Audit through an `Audit\Contracts\AuditLog` contract. Audit's append-only table arrives with the contract.

## Security

| Req | What gets built |
|---|---|
| SEC-03 | Argon2id; breached-password check through a `BreachedPasswordChecker` interface (k-anonymity range API; Fake driver), minimum 12 characters |
| SEC-04 | MFA required for creator, moderator and admin roles, enforced by middleware. A creator without MFA is sent to set it up. |
| SEC-05 | Max 3 active devices; remote session revoke |
| SEC-14 | Redis rate limits on login, OTP send and verify, passkey assertion and registration |
| SEC-15 | `/admin` Filament panel: MFA mandatory, IP allow-list from config, SSO behind a config switch (provider undecided) |
| SEC-01/02 | Security-header middleware (HSTS, CSP with nonce, X-Frame-Options DENY, Referrer-Policy), with header tests |
